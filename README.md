# Nora IDE — téléchargements

Versions publiées de **Nora IDE**, l'IDE pensé pour les développeurs Symfony qui codent avec l'IA.

Téléchargez la dernière version dans l'onglet **[Releases](https://github.com/Jonathanlight/nora-releases/releases/latest)** :

| Plateforme | Fichier |
|---|---|
| macOS (Apple Silicon) | `.dmg` — signé Developer ID et notarisé par Apple |
| Windows (x64) | `.exe` (installeur) ou `.msi` (déploiement en parc) |
| Ubuntu / Debian | `.deb` |
| Fedora / RHEL | `.rpm` |

Chaque release contient `SHA256SUMS.txt` : comparez l'empreinte du fichier téléchargé avant de l'installer.

Ce dépôt ne contient que les paquets publiés. Licence : Apache-2.0.
